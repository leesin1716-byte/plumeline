    Plumeline

    Satellites already see the biggest methane leaks in the world's gas fields. Plumeline puts every overpass on a shared ledger, makes each leak a case that only the satellite can close, and carries the result onto the LNG cargo the gas ends up in.

    1. Real data. 26 Tanager overpasses of six real Permian sources (Carbon Mapper), June – October 2026, posted 30 days after capture, as Carbon Mapper publishes them.
    2. Real contract. The Solidity contract from the repository runs in an Ethereum virtual machine inside this page. No wallet, no testnet.
    3. Fictional actors. Operators, sites, reports, the LNG plant and the importer are invented.
